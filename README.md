## Instagram

No `index.html`, procure:

```html
<a href="#" id="instagramLink">◎ Instagram <span id="instagramHandle">@seuinstagram</span></a>
```

Troque por exemplo para:

```html
<a href="https://www.instagram.com/SUA_CONTA/" target="_blank" rel="noopener">
  ◎ Instagram <span>@SUA_CONTA</span>
</a>
```

Substitua `SUA_CONTA` pelo Instagram verdadeiro.
