# Landing Page — Bolas de Natal Personalizadas

Página criada a partir das duas referências visuais enviadas.

## Estrutura

- `index.html` — estrutura da landing page
- `styles.css` — identidade visual, layout responsivo e componentes
- `script.js` — seleção de cor, quantidade, total e CTA
- `assets/` — recortes das imagens enviadas usados na composição

## Como executar

Abra `index.html` diretamente no navegador.

## Para colocar em produção

Substitua:
- `SUA LOGO / AQUI` pela identidade da marca;
- textos de depoimentos pelos reais;
- preços e regras de desconto;
- botão de compra por checkout/WhatsApp/Mercado Pago/Shopify/etc.;
- imagens recortadas pelos arquivos finais do produto, de preferência em PNG/WebP com fundo transparente.

As fontes usadas são carregadas do Google Fonts. Para uma versão 100% offline, remova o `@import` do `styles.css` e utilize fontes locais.
